First release of **WordCraft AR** — Arabic typography and Iraqi service-writing tools built into [WordCraft](https://github.com/storytold/wordcraft) 0.7.0.

## Downloads
- **`WordCraft-AR-0.7.0-windows-x64.msi`** — Windows installer (64-bit). Self-contained: no internet, no Visual C++ redistributable needed; copy it to a USB stick for an offline machine. Installs beside WordCraft, with Start-menu and desktop shortcuts and the ServiceWord-AR engine.
- **`WordCraft-AR-0.7.0-windows-x64-portable.zip`** — the same program without an installer: unzip and run `WordCraft AR.exe`.

## What's inside
- **Service tab** (كتابات الخدمة): Renumber Cycle (`١.` → `أ.` → `أولاً.` → `(١)` …), Service List, Final Dot, Classification stamp (محدود، سري…), Arabic-Indic page numbers `( ١ - ٥ )`, Kashida justification (Low / Medium / High / Distribute), Format with ServiceWord-AR (± print PDF).
- Arabic list formats saved as standard `.docx` numbering (abjad letters, Arabic-Indic digits, ordinal words).
- New documents are Arabic by default: right-to-left, Times New Roman 14 pt, Arabic-Indic digits in context (File › Options switches it off).
- Complete Arabic interface (2 600+ strings) with a bundled Arabic UI font; the interface follows the system language.
- Visual help: every Service and Mailings button shows a drawn thumbnail and an explanation (English + Arabic) on hover.
- Old computer mode (no animations, fastest start) and a whole-program-optimised, stripped build for slow machines.
- Separate identity from WordCraft (own app id, settings folder and installer), so both can be installed together.

*Nothing to install besides the .msi: the ServiceWord-AR engine ships with its own embedded Python. For old machines, File › Options › General › Old computer mode turns every animation off.*
