Second release of **WordCraft AR** — Arabic typography and Iraqi service-writing tools built into [WordCraft](https://github.com/storytold/wordcraft) 0.7.0. Everything in [ar.1](v0.7.0-ar.1.md), plus:

## Downloads
- **`WordCraft-AR-0.7.0-windows-x64.msi`** — Windows installer (64-bit). Self-contained: no internet, no Visual C++ redistributable, no Python needed; copy it to a USB stick for an offline machine.
- **`WordCraft-AR-0.7.0-windows-x64-portable.zip`** — the same program without an installer: unzip and run `WordCraft AR.exe`.

## New in ar.2
- **Visual help on every button and every menu item.** All 457 ribbon buttons and menu choices (Home to Table Layout, Developer and Zotero included) show a drawn thumbnail of what they do and a plain-words explanation ending in a concrete example, in English and Arabic. The thumbnails play as little films (the arrow grows, the result wipes in, the stamp comes down, the kashida stretches), menu items show their picture beside their name, and buttons answer the pointer with motion.
- **Right-to-left interface.** With the Arabic interface the tabs, the ribbon groups, the buttons, the title bar and the status bar run from the right.
- **Kashida in Home.** Low / Medium / High / Distribute sit beside the Paragraph group; the Service tab keeps the numbering cycle, classification and engine.
- **Clearer icons** for the kashida levels and the renumber cycle; one icon map for every command (no more lettered tiles in custom groups or the Quick Access Toolbar).
- **Built-in developer systems** under *Developer › WordCraft AR*: the UI Kit gallery (every command with its icon, thumbnail, English and Arabic), the icon sheet, a self-test that runs every ribbon button on a scratch Arabic document, and a checklist. `docs/ar-ui-kit.md` explains how to add a button in five steps, and how to lift the kit into GridCraft / DeckCraft.
- `scripts/ar-check.sh` — the fork's quick test gate; `cargo run --example kit_sheet` renders the thumbnail and icon sheets for review.
